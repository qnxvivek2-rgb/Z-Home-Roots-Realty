Z Home Roots Realty — Admin

Local tool to manage properties. Nothing is published automatically — you download the updated projects.json and copy photos in, then publish.

1. Load current data

Loads the existing projects.json. If it can't auto-load (opened directly as a file), pick it manually.

Add a new property

Fill the details, select photos, then click Apply. Slug/folder is auto-generated from the title.

Add photos to an existing property

Pick a property (grouped by city), add more photos. New photos are appended after the current ones.

2. Review & download

After applying changes, the updated JSON appears below. Download it and replace the project's projects.json.

Load data to begin…

3. Photo files to copy in

Copy these exact files into the folders shown (create the folder if it's a new property). Filenames must match exactly.

4. Publish

Once the JSON is saved and photos are copied in, publish with git:

git add projects.json assets/projects
git commit -m "Update properties via admin"
git push origin main
